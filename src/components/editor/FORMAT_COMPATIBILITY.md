# 编辑器格式功能兼容性

本文档描述富文本编辑器在不同光标/选区上下文中允许和禁止的格式功能，以及这些组合在 Markdown 导出/导入中的往返表现。实现以 `src/lib/tiptap-formatting-context.ts` 为准；修改能力规则时请同步更新本表。

## 判定语义

- **折叠光标**：以光标所在的文本块（段落、标题、列表项内的段落、引用内的段落、表格单元格内的段落、代码块）为上下文。
- **范围选区**：按 `selection.ranges` 收集所有被触及的文本块。
- **严格语义**：每个选中的文本块都必须支持该功能，任意一个块不支持就禁用。例如“标题 + 正文”的选区会禁用粗体；`Ctrl+A` 选中含代码块的文档会禁用所有行内格式。
- **非文本选区**：图片等 `NodeSelection` 与间隔光标（`GapCursor`）没有文本块，所有行内格式和块级转换都禁用；撤销/重做不受影响。
- **优先级**：代码块限制 > 标题/表头/表格单元格限制 > 行内代码开放。例如“标题里的行内代码”仍禁用粗体，但允许斜体；表格单元格里的行内代码仍禁用块级格式。
- **禁用即不响应**：工具栏按钮显示为禁用；对应快捷键被吞掉；Markdown 输入/粘贴规则不执行，字面标记（`**`、`` ` `` 等）保留。
- **粘贴清理**：粘贴/拖入的内容在插入前按光标上下文清理，避免产生无法取消的格式——目标为标题/表头时移除粗体；粘贴进表格单元格时把标题、列表、引用、代码块展开为段落（水平分割线直接丢弃）；代码块内粘贴会移除全部 mark。Markdown 导入（文件菜单）不走这条路径，仍可能产生标题内的粗体等组合。
- **快捷键不要加大小写别名**：`prosemirror-keymap` 在 Shift 组合下会先做“去 Shift”查找，因此再注册一个 `Mod-B` 会先于 `Mod-Shift-b` 命中并吞掉引用快捷键。CapsLock 场景已由 keyCode 回退覆盖，无需大写别名。

## 支持矩阵

“普通文本块”指段落、列表项、引用内部。表格单元格（`th` / `td`）只允许行内格式：GFM 表格只支持行内内容，单元格内的标题、列表、引用、代码块都无法通过 Markdown 往返，因此这些块级格式在表格中被禁用。`行内代码` 是 mark，可与标题/表头/普通块叠加，因此单独列出。

| 功能 | 普通文本块 | 标题 h1–h6 | 表头 th | 正文 td | 行内代码内 | 代码块 | 非文本选区 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 粗体 | ✓ | ✗（标题已加粗） | ✗（th 已加粗） | ✓ | ✓ | ✗ | ✗ |
| 斜体 | ✓ | ✓ | ✓ | ✓ | ✓ | ✗ | ✗ |
| 删除线 | ✓ | ✓ | ✓ | ✓ | ✓ | ✗ | ✗ |
| 下划线 | ✓ | ✓ | ✓ | ✓ | ✓ | ✗ | ✗ |
| 行内代码 | ✓ | ✓ | ✓ | ✓ | ✓（再次点击取消） | ✗ | ✗ |
| 链接 | ✓ | ✓ | ✓ | ✓ | ✗ | ✗ | ✗ |
| 标题级别 / 正文 | ✓ | ✓ | ✗ | ✗ | ✓ | ✗ | ✗ |
| 无序 / 有序列表 | ✓ | ✗（标题不能转成列表） | ✗ | ✗ | ✓ | ✗ | ✗ |
| 引用 | ✓ | ✓ | ✗ | ✗ | ✓ | ✗ | ✗ |
| 代码块开关 | ✓ | ✓ | ✗（已有代码块内可退出） | ✗（已有代码块内可退出） | ✓ | ✓（用于退出） | ✗ |
| 水平分割线（仅 Markdown 输入规则） | ✓ | ✗ | ✗ | ✗ | ✗ | ✗ | ✗ |
| 插入表格 | ✓ | ✓ | ✗ | ✗ | ✓ | ✗ | ✗ |
| 表格操作（合并/拆分/删表等） | — | — | — | — | — | — | 仅在表格内可用 |
| 撤销 / 重做 | 跟随 `canUndo` / `canRedo` | 同左 | 同左 | 同左 | 同左 | 同左 | 同左 |
| 文档导入/导出 | 始终可用 | 始终可用 | 始终可用 | 始终可用 | 始终可用 | 始终可用 | 始终可用 |

补充说明：

- “行内代码内”列表示普通文本块中的行内代码；若行内代码位于标题/表格/代码块，仍以所在块的限制为准（例如标题里的行内代码仍禁用粗体）。
- `Code` mark 设置 `excludes: 'link'`：粗体/斜体/删除线/下划线可与行内代码共存，链接与行内代码双向互斥。
- 标题/表头禁用粗体是因为 CSS 已将 `h1`–`h6` 与 `th` 固定为 `font-weight: 600`，再加粗没有可见效果。
- 块级 Markdown 输入规则（`# `、`- `、`1. `、`> `、代码围栏、`---`）与 mark 输入规则一样受能力层约束；在不支持的上下文中会保留字面文本，不会转换。
- 下划线在渲染侧使用 `<u>`；`PostContent` 的 sanitizer 已显式允许该标签。

## Markdown 兼容性

使用 `@tiptap/markdown` 对矩阵中允许的组合做序列化 → 解析往返验证。扩展注册顺序为：

```ts
[ContextualBold, StarterKit.configure({ bold: false, code: false }), ContextualCode]
```

| 组合 | 导出的 Markdown | 再导入 |
| --- | --- | --- |
| 标题 + 斜体 | `# *标题*` | ✓ |
| 标题 + 删除线 | `# ~~标题~~` | ✓ |
| 标题 + 下划线 | `# <u>标题</u>` | ✓（依赖 `<u>`） |
| 标题 + 行内代码 | `` # `标题` `` | ✓ |
| 标题 + 链接 | `# [标题](url)` | ✓ |
| 行内代码 + 粗体 | `` **`代码`** `` | ✓ |
| 行内代码 + 斜体 | `` *`代码`* `` | ✓ |
| 行内代码 + 删除线 | `` ~~`代码`~~ `` | ✓ |
| 行内代码 + 下划线 | `` <u>`代码`</u> `` | ✓（依赖 `<u>`） |
| 行内代码 + 粗体 + 斜体 | `` ***`代码`*** `` | ✓ |
| 行内代码 + 斜体 + 删除线 + 下划线 | `` *~~<u>`代码`</u>~~* `` | ✓（依赖 `<u>`） |
| 标题 + 粗体 + 行内代码（Markdown 导入） | `` # **`标题`** `` | ✓ |
| 列表项 + 行内代码 + 粗体 | `` - **`条目`** `` | ✓ |
| 引用 + 行内代码 + 斜体 | `` > *`引用`* `` | ✓ |
| 表头 + 斜体 / 行内代码 / 链接 / 下划线 | GFM 表格 | ✓（下划线依赖 `<u>`） |
| 表格正文 + 行内代码 + 粗体 | GFM 表格 | ✓ |
| 行内代码 + 链接 | `` [`代码`](url) `` | schema 已禁止，不会产生 |

表格单元格只开放行内格式，因此上表只列出单元格内的行内组合；“单元格内标题/列表/引用/代码块”已被能力层禁用，粘贴时也会被展开为段落，不会产生无法往返的 Markdown。Markdown 导入不会产生单元格内的块级内容。

关键约束：

- **`ContextualCode` 必须最后注册**（在其他行内 mark 之后获得最高 rank）。Markdown 序列化按 mark rank 由外到内嵌套；如果 Code 早于 Italic/Strike/Underline 注册，会导出 `` `*代码*` ``、`` `~~代码~~` ``、`` `<u>代码</u>` ``，再导入时整个字符串被当成代码内容，格式丢失。粗体在两种顺序下都能正确导出为 `` **`代码`** ``，但不能因此保留旧顺序。
- **下划线**使用原始 `<u>` 标签，不是标准 Markdown。本项目自身可以往返，第三方 Markdown 渲染器可能不支持。

## 相关文件

- `src/lib/tiptap-formatting-context.ts`：上下文读取、能力矩阵、`canApplyFeature` / `getEditorCapabilities`
- `src/lib/tiptap-paste-cleaner.ts`：粘贴/拖入内容的清理（mark 过滤、单元格内块级内容展开）
- `src/components/editor/editor-contextual-marks.ts`：`ContextualBold`（标题/表头内禁用 Markdown 粗体规则）、`ContextualCode`（`excludes: 'link'`）
- `src/components/editor/editor-contextual-blocks.ts`：标题/列表/引用/代码块/水平分割线的输入规则守卫
- `src/components/editor/editor-formatting-guards.ts`：按上下文吞掉快捷键，并挂载粘贴清理插件
- `src/components/editor/EditorToolbar.tsx`：按钮禁用状态与下划线按钮
- `src/components/PostContent.tsx`：sanitizer 保留 `<u>`
